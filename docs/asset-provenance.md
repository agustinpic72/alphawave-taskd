# Asset Provenance

All visual assets in this repository were created for AlphaWave TaskD by Agustin Piccoli and are distributed under the repository's Apache-2.0 license. No stock imagery, copied branding, bundled font file, or third-party icon pack is redistributed.

The vector brand uses original geometric paths and platform-provided system sans-serif fonts. The raster app icons are renderings of that original vector mark. Public screenshots are generated from a temporary SQLite database by `scripts/dev/generate-demo-screenshots.sh`; they contain synthetic `[DEMO]` tasks only.
