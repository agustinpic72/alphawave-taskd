# AlphaWave TaskD v0.1.0 — Initial Open-Source Release

AlphaWave TaskD is a local-first task command center built with FastAPI, React, TypeScript, and SQLite.

## Included

- Task capture, search, planning, reminders, completion, trash, and recovery flows.
- Explainable priority suggestions and confirmation queues.
- Optional OpenAI-assisted task details with deterministic fallback.
- Optional Telegram commands and Trello synchronization.
- Docker Compose and native development workflows.
- Automated backend, frontend, browser, publication, dependency, and container checks.

## Install

```bash
git clone https://github.com/agustinpic72/alphawave-taskd.git
cd alphawave-taskd
docker compose up --build
```

Open <http://localhost:8711>. The default setup requires no external credentials.

## Optional Integrations

Telegram, Trello, and OpenAI are disabled by default. Configure them only with dedicated credentials and follow the in-app confirmation boundaries. Routine tests and CI do not call live integrations.

## Security and Data Boundaries

SQLite data remains local to the installation. Keep `.env`, databases, backups, logs, and diagnostics private. Non-local deployment requires deliberate authentication, TLS, reverse-proxy, cookie, backup, and monitoring configuration; see [SECURITY.md](../../SECURITY.md).

## Known Limitations

- In-process workers and SQLite target local or single-instance operation.
- This release is not a hosted multi-tenant SaaS.
- High availability, managed monitoring, tenant isolation, and commercial support are not included.
- Docker CI runs on Linux; Docker Desktop paths are documented but manually verified.
