# Open-Source License Decision

Apache-2.0 has been selected for AlphaWave TaskD. The root `LICENSE` file contains the Apache License, Version 2.0.

## Options

### MIT

Best when the goal is maximum simplicity and broad adoption. It is short, familiar, and permissive, but it does not include an explicit patent grant.

### Apache-2.0

Best when the goal is permissive open source with clearer patent language. It is a strong default for a public portfolio project that may later accept contributions.

### AGPL-3.0

Best when the goal is to require source sharing from network-hosted derivatives. It offers stronger copyleft protection, but it can discourage commercial or embedded reuse.

## Decision

Apache-2.0 is the selected license because it is permissive, familiar for public portfolio projects, and includes explicit patent language.

## Notes

- MIT remains the simpler permissive alternative, but was not selected.
- AGPL-3.0 remains a stronger copyleft/SaaS-protective alternative, but was not selected.
- Contributions are expected under Apache-2.0 unless explicitly stated otherwise.
