# Support

AlphaWave TaskD is maintained as an open-source project without guaranteed response times, uptime, data recovery, or commercial support.

For reproducible bugs and focused feature requests, use the repository's GitHub issue templates. For setup questions, check the [README](README.md), [Docker guide](docs/docker.md), and [operations guide](docs/operations.md) first.

Security reports must follow [SECURITY.md](SECURITY.md) and must not be posted publicly.

When asking for help:

- Use synthetic examples.
- Include the operating system, container/runtime versions, release or commit, and exact reproduction steps.
- Redact credentials, personal data, integration IDs, hostnames, local paths, and database contents.
- Do not upload `.env`, SQLite databases, backups, logs, or diagnostic bundles unless a maintainer explicitly requests a sanitized excerpt.

Live integration configuration and self-hosted deployment remain the operator's responsibility.
