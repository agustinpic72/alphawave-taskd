# Roadmap

AlphaWave TaskD is a local-first application. This roadmap describes direction, not a delivery commitment.

## Now

- Keep the Docker Compose quick start reliable on Linux and documented for Docker Desktop.
- Maintain deterministic synthetic screenshots and browser smoke coverage.
- Strengthen task planning, reminders, settings, backups, and diagnostics.
- Keep Telegram, Trello, and OpenAI integrations optional and disabled by default.
- Improve accessibility, responsive behavior, and contributor documentation.

## Next

- Expand authentication and per-user isolation for carefully operated private deployments.
- Improve operational visibility for background jobs and optional integrations.
- Add safer import/export workflows and clearer recovery guidance.
- Reduce migration-only complexity after compatibility and rollback review.

## Later

- Evaluate PostgreSQL and separately deployed workers.
- Explore OAuth-based integration onboarding.
- Consider a dedicated mobile experience.
- Evaluate hosted or multi-tenant architecture only after isolation, operations, privacy, abuse prevention, and support requirements are designed and tested.

AlphaWave TaskD does not currently promise a hosted service, multi-tenant isolation, high availability, or managed support.
